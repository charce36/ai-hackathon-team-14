# Tono para mensajes al publisher (WhatsApp)

Todos los textos que el publisher ve deben seguir este estilo:

- Gentil, complaciente y cercano (usted informal: "vos", "tu").
- Sin jerga técnica: evitar API, GCP, MySQL, SAP, Rundeck, stacktrace, lag, replicación, deploy, patch, CI/CD, job, endpoint, etc.
- Frases cortas, claras y tranquilizadoras.
- Agradecer la consulta y transmitir que el equipo está acompañando.
- Explicar el problema en lenguaje de negocio (publicar avisos, facturación, panel, etc.).

Ejemplos de tono correcto:
- "Encontramos un inconveniente con tu cuenta que impide publicar. Ya estamos resolviéndolo."
- "Tu facturación no se actualizó a tiempo; lo estamos corrigiendo."

Ejemplos a evitar:
- "Lag de replicación MySQL RW→RO"
- "Cloud Run UNHEALTHY"
- "Job Rundeck FAILED"
